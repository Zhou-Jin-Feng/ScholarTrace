# ScholarTrace 工作台

## 启动与操作

保持现有 React 18 / TypeScript / Vite 技术栈。后端按根目录 README 启动，
前端在 `frontend/` 运行 `npm ci --ignore-scripts`、`npm run dev`。
开发代理将 `/api` 转发到本机8000端口；生产静态文件由既有部署层提供，不改变认证边界。

1. 新建问题只创建任务，不自动批准或执行。当前页面只开放明确标识的 Demo。
2. 读取规划费用估算，勾选确认后生成计划。未知估算不能直接批准。
3. 审阅计划版本、指纹、来源、年份、论文数量、排除项和预算。
4. 修改只保存新待审版本；必须另行批准新版本。旧版本冲突会重新读取，不自动再批准。
5. 运行概览展示真实持久化事件、预算预留、已知计量下界及结算状态；没有虚构百分比。
6. 报告支持 PDF / Markdown / HTML / JSON。报告末尾的论断入口可打开对应证据原文。
7. 证据视图区分原文与推断，缺失页码或版本显示“未提供”；被排除论断仍可查看。

列表采用后端游标分页，状态筛选在服务端执行；搜索框只搜索已加载任务，标签明确说明范围。
所选任务保存在 URL fragment 中，支持刷新及前进后退，不把研究问题或令牌写进 URL。
访问令牌通过右上角设置，仅保存在页面内存，刷新后需重新输入。
普通请求及报告下载使用 Bearer header；原生 SSE 保留既有 query token 兼容方式，
部署需 TLS 并关闭查询串访问日志。

## 来源与能力边界

- 普通确定性 Demo 不提供结构化研究论断。离线研究 runner 是服务端显式依赖注入，
  并非用户可开启真实网络的 HTTP 参数。
- Fixture 核验始终显示“未核验”，同时保留原始判定、partial/conflict标记及排除信息。
- 当前离线组合只接受 fixture 计划。手动修改后来源为 manual，不可据此声称已通过
  离线研究组合验收；默认 Demo 与生产研究的能力范围也不同。
- Real 执行器及真实 Coordinator 的生产装配已就绪（N1–N3，工程验证范围内通过）；尚未通过验证的是真实在线全链路，并非仅缺环境变量。
- 配置存在不等于依赖已探活。unknown / disabled / unavailable / degraded保留原义。
- 中断恢复只允许原批准身份及明确支持的离线 runner，最多两次；未知外部副作用不自动重发。
- 离线阶段事件可能在研究组合返回后集中进入交付事件流，不等于阶段执行时即时推送。

## 前端模块

| 目录 | 职责 |
|---|---|
| `src/main.tsx` | 挂载根组件与样式 |
| `src/app/` | 工作台外壳、任务导航和内存认证状态 |
| `src/features/tasks/` | 创建、分页历史、任务详情、预算和时间线 |
| `src/features/plans/` | 两道确认、版本绑定审批、修改表单 |
| `src/features/reports/` | 安全纯文本Markdown阅读、报告导出、论断导航 |
| `src/features/evidence/` | 论断、原文、定位与文档归属 |
| `src/api/` | HTTP契约、错误规范化和请求封装 |
| `src/hooks/` | 可取消资源读取、具名SSE和有限重连 |
| `src/components/` | 状态、来源核验标记和共享状态组件 |
| `src/styles/` | 视觉变量、外壳布局、业务视图及响应式规则 |

服务端数据与当前视图/选中证据等界面状态分离。任务切换时卸载旧详情，取消旧读取与事件流，
过期回调不能覆盖新任务。SSE去重与持久化时间线按sequence合并；失败、取消不提前截断导出事件。
报告不执行原始HTML、不自动加载远程图片；服务端与客户端都不把Markdown当脚本执行。

## PDF

PDF导出保留全部行，按A4分页，长段落自动换行，支持中文和ASCII并保留可复制的Unicode映射。
渲染完全本地，无浏览器、模型、在线字体或额外产品依赖。相同输入生成相同字节。
中文使用Adobe-GB1标准STSong-Light替代字体，需要阅读器支持CJK字体替代；并非嵌入字体的PDF/A。
不承诺emoji、所有生僻扩展字符、复杂数学公式或完整Markdown排版；完整源文本可使用Markdown导出。
已有持久化报告不被后台重写，改进适用于新生成的导出。

## 验证

`npm test` 覆盖审批门禁、旧版本拒绝、来源标记、资源切换、时间线合并、预算未知值、
安全文本渲染及报告—论断—证据导航；`npm run build`运行类型检查和生产构建。
后端PDF回归覆盖中文、多页、长行、尾行、空文档、转义与确定性。
真实服务质量、完整部署矩阵和跨浏览器可访问性需分别验收，不由组件测试代替。
